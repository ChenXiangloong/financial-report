# financial-report

金融研究报告合集，全部为静态 HTML 页面，可直接在浏览器打开。

## 目录

- [纯债基金对话存档](pure_bond_fund/)：什么是纯债基金 / 纯债基金的定义（ChatGPT 与 Claude 两份对话存档入口）
- [可转债与债基对话存档](convertible_bond_fund/)：可转债、一级债基、二级债基与纯债的区别，以及一级/二级市场含义（ChatGPT 与 Claude 两份对话存档入口）
- [A股长期投资对话存档](ashare_longterm/)：A股长期投资 / A股长期投资的可行性与挑战（ChatGPT 与 Claude 两份对话存档入口）
- [10年20万元A股债券投资计划对话存档](ashare_20w_10y_plan/)：同一份投资需求的四轮对话（ChatGPT 与 Claude 两份存档入口）
- [日本股市与经济关联对话存档](japan_stock_economy/)：过去 40 年日本股市与经济状况的关联（ChatGPT 与 Claude 两份对话存档入口）
- [QDII美股基金限购对话存档](qdii_analysis/)：限购成因、历史与十年规模趋势（ChatGPT 与 Claude 两份对话存档入口）
- [字节跳动期权回购调查](bytedance_option_buyback/)：2018–2026 历次回购价格
- [沪深300 vs 中证500](hs300_vs_zz500_20y/)：过去 20 年收益、波动与回撤对比
- [投资组合回测](portfolio_backtest/report.html)：60/40 与 30/70 双组合历史回测
- [债券基金19只汇总评估](bond_funds_19/)：久期·信用持仓·杠杆·最大回撤·收益·费率·赎回限制七维横评，含功能位重排与5年互补组合建议

## 浏览

打开 `index.html` 可查看全部文章的导航首页。

## 说明

- 所有图表基于 ECharts，离线即可渲染。
- 数据来源与口径见各页面内的说明。
- 对话存档类页面为 SingleFile 保存的原始网页（含界面与样式），体积较大，首次打开可能需要几秒。
